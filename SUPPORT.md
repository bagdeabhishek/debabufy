# Support

## Usage questions and bugs

Read the [README](README.md) and the selected workflow's documentation first.
For Form 141, see its
[troubleshooting guide](workflows/form-141/docs/TROUBLESHOOTING.md). If the
problem remains, open a GitHub issue using the appropriate template.

This is a volunteer-maintained alpha project. Support, response times, portal
compatibility, and tax outcomes are not guaranteed.

## Tax questions

The project cannot determine the correct tax treatment for a transaction. Ask a
qualified tax professional about rates, interest, fees, dates, eligibility, or
whether a Form 141 Schedule B filing is required.

## Sensitive or security matters

Do not place private filing data in an issue. Report vulnerabilities privately
as described in [SECURITY.md](SECURITY.md).

Never share a real statement, HAR, diagnostic file, taxpayer identifier,
contact detail, property address, credential, OTP, payment reference, bank
detail, browser profile, or unredacted portal screenshot with this project.
