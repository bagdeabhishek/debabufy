# Code of conduct

We want this project to be a respectful, privacy-conscious place to collaborate.

## Expected behavior

- Be constructive, patient, and specific.
- Respect differing experience levels and viewpoints.
- Protect taxpayer and financial privacy.
- Use synthetic data in all public collaboration.
- Focus criticism on code and behavior, not people.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private or identifying information.
- Requesting or sharing real filing data, credentials, OTPs, or payment details.
- Using the project to bypass authentication, validation, or payment controls.

## Enforcement

Maintainers may edit or remove contributions and restrict participation when
needed to protect contributors, users, or sensitive information. Serious
security concerns should be reported privately according to
[SECURITY.md](SECURITY.md).
